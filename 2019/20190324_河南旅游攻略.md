# 河南旅游攻略

[唐书房](https://laotang.pages.dev/people/唐朝) 2019-03-24 3月24日到南阳,初步计划南阳—信阳—许昌—登封—洛阳—郑州—开封—商丘,离开河南。但据说洛阳牡丹要4月10日左右才盛开,距今还有18天,清明3天长假可以住在某城市躲人流,剩余15天。哪位河南通能设计一个旅游攻略,能够一路玩过去,且4月10号还在洛阳?——参与话题讨论，分奖金✌️
