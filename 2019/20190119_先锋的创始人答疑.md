# 先锋的创始人答疑

1月16日，指数基金之父，先锋领航集团创始人、多次被沃伦.巴菲特点赞并推荐的投资界名人约翰.伯格老先生离世，享年89岁（其实按中国人的算法，应该说90岁，老先生1929年出生）； 因为恰好1月3日书房文章里提及过巴菲特有位好友叫菲利普.卡特雷，是先锋基金的创始人，已经于1998年5月离世，享年101岁。导致部分朋友发信息来问老唐：究竟谁才是先锋的创始人？ 老唐统一做个解释：这是中文翻译的锅。菲利普.卡特雷（也有翻译为菲利普.凯特瑞的）创立的基金叫Pioneer，中文意思先驱、先锋、拓荒者，是一个主动管理基金，创立于1928年； 而约翰.伯格创立的基金叫Vanguard，中文意思也是先驱、前卫、先锋等，通常翻译为先锋领航集团，创立于1974年，是美国指数基金领域的三大巨头之一。 我曾见过有资料说约翰.伯格的公司是从卡特雷的公司演化出来的。但该份中文资料来源不太可信，而老唐英文又很渣，没有考证过英文资料，个人倾向于认为两者之间没有任何股权或继承关系。 大致就是这样的，周末愉快！
