# 涨了要减仓避险吗？

2019年短短33个交易日，股市大盘涨起来超过22%，书房不少朋友赚的有点胆战心惊。最近收到最多的问题是「短期涨这么多，是不是应该暂时回避一下？」有这些心思的朋友，老唐不能（也不应该）替你拿主意，但推荐你重读书房去年8月19日的文章《股市下跌，应该顺势而为、减仓避险吗？》 链接在此→[https://mp.weixin.qq.com/s/TEEso5pssJFakZFTuwYDmQ——想着是不是也挺好玩的？几个月前每天弥漫的是对下跌的恐惧，这么快就换成对上涨的恐惧了](https://mp.weixin.qq.com/s/TEEso5pssJFakZFTuwYDmQ%E2%80%94%E2%80%94%E6%83%B3%E7%9D%80%E6%98%AF%E4%B8%8D%E6%98%AF%E4%B9%9F%E6%8C%BA%E5%A5%BD%E7%8E%A9%E7%9A%84%EF%BC%9F%E5%87%A0%E4%B8%AA%E6%9C%88%E5%89%8D%E6%AF%8F%E5%A4%A9%E5%BC%A5%E6%BC%AB%E7%9A%84%E6%98%AF%E5%AF%B9%E4%B8%8B%E8%B7%8C%E7%9A%84%E6%81%90%E6%83%A7%EF%BC%8C%E8%BF%99%E4%B9%88%E5%BF%AB%E5%B0%B1%E6%8D%A2%E6%88%90%E5%AF%B9%E4%B8%8A%E6%B6%A8%E7%9A%84%E6%81%90%E6%83%A7%E4%BA%86)
