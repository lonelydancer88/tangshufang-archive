# 图示转债申购

![](https://laotang.pages.dev/articles/images/docx/image556.webp) 终于今天有新可转债申购了，可以截图展示了第一步，进入券商A交易界面，点击“新债申购”， ![](https://laotang.pages.dev/articles/images/docx/image557.webp) 第二步，获得如下界面 ![](https://laotang.pages.dev/articles/images/docx/image558.webp) 第三步，点击前面的方框勾选，并在申购数量里填入申购上限数量，得到下图 ![](https://laotang.pages.dev/articles/images/docx/image559.webp) 第四步，点击新债申购，确认 ![](https://laotang.pages.dev/articles/images/docx/image560.webp) 第五步，拿出你的小本本，记下申购代码和数量，然后去其他账户里操作一遍。 第六步，等中签通知，吃鸡……
