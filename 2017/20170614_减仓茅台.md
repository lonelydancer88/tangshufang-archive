# 减仓茅台

上午在475.5元上方，按计划减仓了茅台。减的数量为持有茅台总量的10%，约占总仓位的4%。 本来计划开通B股，用减仓茅台的资金，买点儿长安B和古井B，出去试试水的。结果昨天跑了一天，没搞定。说是外管局现在对所有涉及投资的外汇购买行为一律采取了严管措施。 银行和券商都暗示，可以用出国旅游等目的购汇，然后一样的购买B股。老唐没敢。胆小，一者这种方式兑换资金数量有限，二者怕我党秋后算账。不值当，索性算了。 减仓资金，抽出来一点装修费用，准备装修房子——老朋友可能还记得，老唐2015年春某日跑步，去跑道边的某售楼部蹭水喝，一时不察，被售楼先生忽悠买了套房子。最近快交房了，正好现在住的房子装修也十年了，旧了，加上小区外通了地铁，嘈杂起来了，索性准备把新房子装了。 加了约1%出头的双汇，还剩余近2%的资金一时找不到方向，就暂时先闲着吧！待老唐这几天追完《白鹿原》之后，再慢慢看财报，慢慢找对象。 个人实盘记录，仅因答应过部分朋友，减仓茅台时会吼一声，故有此文。非投资推荐，请勿依此做出投资决策。 来者可追：万万没想到，在中外古今群星璀璨的大师和伪大师汗牛充栋般的鸿篇巨著中，居然是一个没学历的四川胖子写的文章把我引入了正途。谢谢老唐！为了更多的小白小散，我第三次提议：老唐写一本《手把手教你做“夹头”》吧，把巴神他们的价值投资理念和方法，汇总、梳理、“中翻中”，做中国投资者的入门书，领大家上道——星光大道的道，也是朝闻道夕死可矣的道。我坚信这本书会长期占据投资理财畅销书榜首，什么日本蜡烛图啦、聪明的投资者啦，全得让位！这书写起来也不费力，老唐在雪球和微信公众号已经写了很多了啊，地基已成，不算是挖坑。 作者回复你写的很幽默啊 修羽：老唐手1的166页营收角度的现金流量表这一节中，“如果上市公司所有业务都适合17%增值税率……”这段说将营收乘以1.17来得到收到现金数值，这个算法是不是有问题？17%的税率，意味着税后剩下的是83%，应该是除以83%或者近似一下是乘以1.2吧。如果我说的合理的话，172页第二段也存在类似的情况作者回复你的理解是错的，按我书中所说计算。 李鹏：你好，之前看过您写的关于茅台的文章中说由于股权激励，管理层可能会压低利润，请问这是问什么呢作者回复这，😰你说呢？明年增长10%，给你百万，明年增长30%，给你千万，你会怎么干？🙄 征程：唐老你好，我是一名股市新人，想请教你，作为一名新人，你建议应该从哪里起步，慢慢学会投资呢？可否一边学习一边“抄作业”，还是学到一定程度后再买股？ 作者回复可以少量投资，在干中学。起步嘛，建议先从四本书开始：格老的《聪明投资者》、任俊杰的《穿越迷雾》，老唐的《[手把手教你读财报](https://laotang.pages.dev/books/手把手教你读财报)》，水晶苍蝇拍的《股市进阶之道》。 皇冠上的钻石：终于想起来把腾讯控股理了一遍。两点：第一，7星级好公司（我的评价表里总共9条，最高9星），无论资质和潜力方面都相当出色，唯一的风险就是15年开始大规模融资扩张，使得负债飙升太多。第二，[内在价值](https://laotang.pages.dev/concepts/内在价值)，2017年195港币左右，买入价应该打折买。目前股价泡沫太大。我不参与买入，仅供参考作者回复谢谢分享🤝🤗 自游离：昨天有个问题想不明白，请老唐不吝赐教既然茅台高估减仓，那为何不选择清仓？而且仓位还那么重，夹头不是高估离场，再选择低估品种吗？ 作者回复没高估，前面说过了，这个位置是我心中2017年的合理估值位，没有额外的便宜占了，只是把过重的仓位降低一点点。今年要是敢过750，我就给他清了，等回调
